# بيانات الطلاب لأوراق الاختبارات

تطبيق Android مستقل مقتبس من وحدة «فتح وتحرير ملفات PDF وWord» في مشروع Exam Maker App.

## الوظائف

- فتح ملفات PDF وعرضها وحفظ نسخة منها وطباعتها.
- فتح مستندات Word بصيغة DOCX وتحريرها وحفظها أو طباعتها.
- تحويل مستند Word المحرر إلى PDF عند إنشاء نسخ الطلاب.
- استيراد كشف الطلاب من Excel بصيغ XLSX وXLSM.
- تصفية الطلاب وفق الصف وورقة المادة.
- استخراج الرقم السري للطالب، أو توليده وفق القاعدة الموجودة في كشف Excel.
- حساب كود المادة/الفترة آلياً وفق ترتيب أوراق المواد أو أسماء الأشهر في الصف الثاني.
- إنشاء نسخة PDF لكل طالب، مع الاسم ورقم الجلوس ورمز QR وكود المادة في الصفحة الأولى.
- دعم الطباعة عبر خدمات Android والطابعات المتاحة.

## البنية

يحتوي هذا المستودع على واجهة المستندات وخدمة قراءة Excel ومحرك PDF/QR الأصلي فقط، مع متطلبات Flutter وAndroid اللازمة لتشغيلها. لا يحتوي على محرر الاختبارات أو الكنترول أو OMR أو OCR أو نظام التفعيل الخاص بالتطبيق الأصلي.

## البناء

يُبنى APK عبر GitHub Actions من تبويب Actions، أو تلقائياً عند تحديث ملفات التطبيق على الفرع main.
